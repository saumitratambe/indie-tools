# Transcript to LosslessCut CSV

Convert a timestamped transcript into a LosslessCut-compatible chapter/segment CSV.

![GUI](https://img.shields.io/badge/GUI-Tkinter-3776AB) ![License](https://img.shields.io/badge/license-MIT-green)

## What it does

Parses `[HH:MM:SS] text`, bare `HH:MM:SS`, and `M:SS`/`H:MM:SS` timestamp styles out of a transcript and writes a CSV you can import straight into LosslessCut for segment-accurate cutting.

## Requirements

```
# no pip packages needed — standard library only
```

## Run

```bash
python transcript-to-losslesscut-csv.py
```
