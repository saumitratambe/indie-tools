# Batch Image Strip Cropper

Preview a folder of images, auto-match a reference credit strip, and bulk delete or crop it out.

![GUI](https://img.shields.io/badge/GUI-Tkinter-3776AB) ![License](https://img.shields.io/badge/license-MIT-green)

## What it does

Point it at a folder, upload one reference image of the strip/watermark you want gone, and it finds matching regions across every image so you can select-all and delete or crop in one pass.

## Requirements

```
pip install pillow
```

## Run

```bash
python batch-image-strip-cropper.py
```
