# Bulk Video Merger & Overlay

Batch-merge videos and burn in overlays (watermark/logo/text) via FFmpeg.

![GUI](https://img.shields.io/badge/GUI-Tkinter-3776AB) ![License](https://img.shields.io/badge/license-MIT-green)

## What it does

Queue up video files, merge them in sequence, and apply a consistent overlay across the output — all from one window, no command-line FFmpeg flags to remember.

## Requirements

```
# no pip packages needed — standard library only
```

**Also requires (not pip-installable):** ffmpeg

## Run

```bash
python bulk-video-merger-overlay.py
```
